# Landing Page (gaya Linktree)

Satu halaman pautan untuk diletak di bio media sosial.

## Tukar pautan / nama
Edit **`links.js`** sahaja — tukar `name`, `bio` dan setiap `url`.

## Gambar profil
Letak fail `avatar.jpg` dalam folder ini, kemudian dalam `index.html` buang komen pada baris `<img class="avatar" ...>`.

## Deploy ke Vercel
1. Pergi ke https://vercel.com/new dan log masuk dengan GitHub.
2. Pilih repo **LANDINGPAGE** → **Import**.
3. Framework Preset: **Other**. Jangan ubah tetapan lain → **Deploy**.
4. Setiap kali anda push ke `main`, Vercel akan update laman secara automatik.
